The study performs a structural analysis on the Astrophysics network structure 
using graph theory and network science tools. This paper examines astrophysics network 
structure through assessments of centrality along with clustering and degree distribution, 
community detection and power-law modelling to find small-world and scale-free network 
characteristics. The research is based on the dataset used by Newman (2001) and compare 
our findings with other literature on collaboration networks. After research, it is noticed that 
the network has a high clustering coefficient, short average path length, and an assortative 
structure. The network features a power law distribution that descends steeply with an 
exponent value of 3.75 which implies a heavy-tail in its topology.
